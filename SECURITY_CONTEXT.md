# OSEA AI Skill - Security Context

## Project Purpose

OSEA (Open Security Engineering Assistant) is an open-source, AI-assisted security review skill designed to support defensive security engineering.

Its intended capabilities include:

- **Code Auditing:** Reviewing source code for potential security weaknesses.
- **Threat Modeling:** Identifying potential threats, attack surfaces, and security risks.
- **Vulnerability Analysis:** Helping developers understand and assess potential vulnerabilities.
- **Security Recommendations:** Providing actionable remediation guidance to improve software security.

## Security Classification

OSEA is designed for defensive security analysis, secure software development, and security improvement.

The repository's purpose should be evaluated based on its actual source code, documented functionality, and usage instructions.

A third-party classification such as `PoC exploit` does not, by itself, establish that a repository contains a working exploit, malicious payload, or exploitable vulnerability.

## Verification Guidelines

To assess OSEA accurately, reviewers should:

1. Read the project's README and documentation.
2. Inspect the source code and implemented functionality.
3. Distinguish defensive security analysis from exploit execution.
4. Verify third-party security claims against technical evidence.
5. Avoid treating automated labels or risk scores as conclusive without supporting context.
